# Documentação - TA10 / CT32

## Caso de teste

CT32 - Impedir a geração da planilha quando não existem medições no período.

## Observação técnica

No estado atual do projeto, a exportação de planilha não está disponível na API REST. As rotas de API cadastradas em `src/routes/api.js` cobrem autenticação, usuário, histórico e medições, mas não incluem endpoint de exportação.

A funcionalidade de planilha está implementada no fluxo web:

POST `http://localhost:3000/exportar/excel`

Por isso, este caso deve ser validado como teste web ou a API precisa receber um novo endpoint de exportação antes de ser testada como TA.

## Rota web existente

POST `/exportar/excel`

## Autenticação

Necessária. O usuário deve estar logado no sistema web.

## Requisição

Content-Type: `application/x-www-form-urlencoded`

Body:

```text
periodo=7
```

## Resposta esperada quando não há medições no período

O sistema não gera a planilha e redireciona para `/exportar`, exibindo a mensagem:

```text
Nenhuma medição encontrada para o período selecionado.
```

## Resposta esperada quando há medições no período

O sistema retorna um arquivo `.xlsx` com o cabeçalho:

```text
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename=historico-medicoes-<timestamp>.xlsx
```
